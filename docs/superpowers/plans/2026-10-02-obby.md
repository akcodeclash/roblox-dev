# Classic Stage Obby Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a publishable 10-stage Roblox obby with checkpoints, saved progress, and a stage leaderboard.

**Architecture:** Stages are parts in `Workspace.Stages`, built once through the Studio MCP and then owned by the place. Behavior comes from tags (`Checkpoint`, `KillPart`) handled by server `ModuleScript`s that one server entry script starts. The two game rules are pure functions in `Rules`, unit tested first; everything else is verified by playtests driven through the MCP.

**Tech Stack:** Roblox Studio, Luau (`--!strict`), Roblox Studio MCP server, Script Sync (Studio to `src/`), git.

**Spec:** `docs/superpowers/specs/2026-10-02-obby-design.md`

## Global Constraints

- Every script starts with `--!strict`. Every module exposes `start()` except `Rules` and `Touch`, which are libraries.
- Scripts are created and edited as files on disk under `src/`; Script Sync carries them into Studio. After writing a file, confirm it arrived with `script_read`. `execute_luau` cannot create scripts.
- File names decide instance types: `Name.luau` is a `ModuleScript`, `Name.server.luau` is a `Script` with `RunContext = Server`.
- Edit files only while Studio is in Edit mode. Stop any playtest first.
- Every MCP call needs `studio_id`; get it from `list_roblox_studios`.
- No scripts are attached to parts in `Workspace`. No client code. No purchases.
- All progress logic runs on the server.
- Data store: name `PlayerData`, key `User_<UserId>`, value `{ stage = <number> }`, written with `UpdateAsync`, 5 attempts, first retry delay 1 second, doubling, with jitter. Periodic save every 180 seconds.
- Commit messages end with the line `Co-Authored-By: anthonyassistant`.
- Git holds scripts and tools only. Stage geometry lives in the place; the user saves the place with version notes (`Cmd+Option+S`) at the end of every task that changes the world.

### Asset procedure (Creator Store)

The spec makes the Creator Store the first choice for obstacles and props. Whenever a task says "run the asset procedure for X":

1. Call `search_asset` with `scope: "creator_store"`, `priceFilter: "free"`, `assetType: "Model"`, `maxResults: 5`, and the query given in the task.
2. Try at most 3 candidates. For each, call `insert_asset` with `parentPath` set to the stage model.
3. List its scripts: `search_game_tree` with `path` set to the inserted asset and `instance_type: "LuaSourceContainer"`. Read each one with `script_read`.
4. Reject and delete the asset if any script is obfuscated, uses `require` with a number, `loadstring`, `HttpService`, `MarketplaceService`, or `TeleportService`, or if the asset has more than 200 parts.
5. If kept: delete every script inside it, anchor every part, recolor it to the stage color (kill surfaces use `Color3.fromRGB(255, 60, 60)`), and tag kill surfaces `KillPart`.
6. If the asset replaces a builder part the player walks on, copy that part's `Order` attribute onto the asset's walkable part and delete the builder part. Decoration goes off the walking path and gets no `Order`.
7. If no candidate passes, keep the builder parts and move on. Record which outcome happened in the task's commit message.

### Playtest procedure

Whenever a step says "playtest with": start play with `start_stop_play` (`is_start: true`), then call `execute_luau` with `datamodel_type: "Server"` and `code` set to the full contents of `tools/playtest.luau` followed by the lines given in the step. Afterwards read `get_console_output` and stop play with `start_stop_play` (`is_start: false`).

"Console clean" means no errors and no warnings other than lines starting with `[PlayerData]`. Those are expected until the place is published, because data stores are unavailable.

## Review Focus

1. **Stored data is malformed** (not a table, `stage` is a string, `NaN`, infinite, negative, fractional): the player starts on a valid whole stage and nothing errors. Pinned by `Rules.sanitizeStage` tests in Task 1.
2. **A `Checkpoint` part has no `Stage` attribute, or two pads share a number**: touches on the bad pad are ignored, a warning is logged at startup, nothing errors. Pinned in Task 4, Step 7.
3. **A dead character's limbs land on the next checkpoint**: no progress is granted. Pinned in Task 4, Step 8.
4. **The player's stage has no pad** (a stage was removed after they saved): they respawn on the highest pad at or below their stage. Pinned in Task 5, Step 5.
5. **Something that is not a character touches a `KillPart`** (a loose part, the spinner bar brushing lava): nothing errors. Pinned in Task 6, Step 5.

```lua
-- RunUnitTest: discovers and runs unit test cases under ServerStorage.UnitTest.Cases.
-- Each case module returns: function(t) ... end, using t.test(name, fn) and t.expect.
-- Usage: require(ServerStorage.UnitTest.RunUnitTest)(filter, timeout)
--   filter   optional string; runs only case modules whose name contains it
--   timeout  optional seconds per case (default 5)
local ServerStorage = game:GetService("ServerStorage")

local function fmt(v)
	if type(v) == "string" then return string.format("%q", v) end
	return tostring(v)
end

local expect = {}
function expect.equal(actual, expected)
	if actual ~= expected then
		error(string.format("expected %s, got %s", fmt(expected), fmt(actual)), 2)
	end
end
function expect.truthy(value)
	if not value then error(string.format("expected truthy, got %s", fmt(value)), 2) end
end
function expect.falsy(value)
	if value then error(string.format("expected falsy, got %s", fmt(value)), 2) end
end
function expect.throws(fn)
	local ok, err = pcall(fn)
	if ok then error("expected the function to throw, but it returned normally", 2) end
	return err
end

-- Runs one test in isolation with a yield-based timeout.
local function runOne(fn, timeout)
	local done, ok, err = false, false, nil
	local cpuStart = os.clock()
	task.spawn(function()
		ok, err = pcall(fn)
		done = true
	end)
	local waited = 0
	while not done and waited < timeout do
		waited += task.wait()
	end
	local elapsed = waited > 0 and waited or (os.clock() - cpuStart)
	if not done then
		return "timeout", elapsed, string.format("exceeded %.1fs", timeout)
	elseif ok then
		return "pass", elapsed, nil
	else
		return "fail", elapsed, tostring(err)
	end
end

return function(filter, timeout)
	timeout = timeout or 5
	local totals = { run = 0, passed = 0, failed = 0 }
	local sessionStart = os.clock()

	for _, module in ipairs(ServerStorage.UnitTest.Cases:GetDescendants()) do
		if module:IsA("ModuleScript") and (filter == nil or string.find(module.Name, filter, 1, true)) then
			local okRequire, caseFn = pcall(require, module)
			if not okRequire or type(caseFn) ~= "function" then
				totals.run += 1; totals.failed += 1
				warn(string.format("[FAIL] %s | case did not return a function: %s", module.Name, tostring(caseFn)))
			else
				local t = { expect = expect }
				function t.test(name, fn)
					totals.run += 1
					local status, elapsed, message = runOne(fn, timeout)
					if status == "pass" then
						totals.passed += 1
						print(string.format("[PASS] %s > %s (%.3fs)", module.Name, name, elapsed))
					else
						totals.failed += 1
						warn(string.format("[%s] %s > %s (%.3fs) | %s", string.upper(status), module.Name, name, elapsed, message))
					end
				end
				local okRun, runErr = pcall(caseFn, t)
				if not okRun then
					totals.run += 1; totals.failed += 1
					warn(string.format("[FAIL] %s | error while building cases: %s", module.Name, tostring(runErr)))
				end
			end
		end
	end

	print(string.format("[SUMMARY] %d run, %d passed, %d failed, %.3fs", totals.run, totals.passed, totals.failed, os.clock() - sessionStart))
	return totals
end
```

```lua
-- Tests for ServerScriptService.Server.Rules: stage advancing, stored-value cleanup, save merging.
return function(t)
	local Rules = require(game:GetService("ServerScriptService").Server.Rules)
	local expect = t.expect

	-- The pad one above the current stage advances the player.
	t.test("advances to the next stage", function()
		expect.equal(Rules.nextStage(3, 4), 4)
	end)

	-- Touching the current stage's own pad changes nothing.
	t.test("stays when touching the current pad", function()
		expect.equal(Rules.nextStage(3, 3), 3)
	end)

	-- Walking back onto an earlier pad never lowers progress.
	t.test("stays when touching an earlier pad", function()
		expect.equal(Rules.nextStage(3, 1), 3)
	end)

	-- A pad more than one ahead is ignored, so teleporting ahead gains nothing.
	t.test("stays when touching a pad two ahead", function()
		expect.equal(Rules.nextStage(1, 3), 1)
	end)

	-- The finish pad (11) is reached from stage 10 like any other step.
	t.test("advances from the last stage to finished", function()
		expect.equal(Rules.nextStage(10, 11), 11)
	end)

	-- A valid stored stage is kept as is.
	t.test("sanitize keeps a valid stage", function()
		expect.equal(Rules.sanitizeStage(7), 7)
	end)

	-- Missing data means a new player.
	t.test("sanitize turns nil into the first stage", function()
		expect.equal(Rules.sanitizeStage(nil), 1)
	end)

	-- A wrong type is treated as missing.
	t.test("sanitize turns a string into the first stage", function()
		expect.equal(Rules.sanitizeStage("5"), 1)
	end)

	-- NaN is a number that fails comparisons; it must not survive.
	t.test("sanitize turns NaN into the first stage", function()
		expect.equal(Rules.sanitizeStage(0 / 0), 1)
	end)

	-- Infinite values are rejected.
	t.test("sanitize turns infinity into the first stage", function()
		expect.equal(Rules.sanitizeStage(math.huge), 1)
	end)

	-- Stages below the first are raised to the first.
	t.test("sanitize raises zero and negatives to the first stage", function()
		expect.equal(Rules.sanitizeStage(0), 1)
		expect.equal(Rules.sanitizeStage(-3), 1)
	end)

	-- Fractions are rounded down to a whole stage.
	t.test("sanitize rounds a fraction down", function()
		expect.equal(Rules.sanitizeStage(4.7), 4)
	end)

	-- A save never lowers stored progress.
	t.test("merge keeps the stored stage when it is higher", function()
		expect.equal(Rules.mergeStage(8, 2), 8)
	end)

	-- New progress replaces older stored progress.
	t.test("merge keeps the memory stage when it is higher", function()
		expect.equal(Rules.mergeStage(2, 8), 8)
	end)

	-- Nothing stored yet: the memory stage is written.
	t.test("merge uses the memory stage when nothing is stored", function()
		expect.equal(Rules.mergeStage(nil, 5), 5)
	end)

	-- Garbage in storage is treated as nothing stored.
	t.test("merge ignores a malformed stored stage", function()
		expect.equal(Rules.mergeStage("oops", 5), 5)
	end)
end
```

```lua
--!strict
local Rules = {}

Rules.FIRST_STAGE = 1

-- A checkpoint counts only when it is exactly one above the player's stage.
function Rules.nextStage(currentStage: number, touchedStage: number): number
	if touchedStage == currentStage + 1 then
		return touchedStage
	end
	return currentStage
end

-- Turns any stored value into a whole stage number of at least FIRST_STAGE.
function Rules.sanitizeStage(value: unknown): number
	if type(value) ~= "number" then
		return Rules.FIRST_STAGE
	end
	if value ~= value or value == math.huge or value == -math.huge then
		return Rules.FIRST_STAGE
	end
	return math.max(Rules.FIRST_STAGE, math.floor(value))
end

-- A save keeps whichever stage is higher, so stored progress never goes down.
function Rules.mergeStage(storedStage: unknown, memoryStage: number): number
	return math.max(Rules.sanitizeStage(storedStage), memoryStage)
end

return Rules
```

Create `tools/stage_builder.luau`:

```lua
-- Prelude for execute_luau (Edit datamodel). Append a `return buildStage({...})` call after this text.
local CollectionService = game:GetService("CollectionService")
local Workspace = game:GetService("Workspace")

local KILL_COLOR = Color3.fromRGB(255, 60, 60)
local PAD_COLOR = Color3.fromRGB(245, 245, 245)

local function getStagesFolder()
	local folder = Workspace:FindFirstChild("Stages")
	if not folder then
		folder = Instance.new("Folder")
		folder.Name = "Stages"
		folder.Parent = Workspace
	end
	return folder
end

local function newPart(className, name, size, position, color, parent)
	local part = Instance.new(className)
	part.Name = name
	part.Anchored = true
	part.Size = size
	part.Position = position
	part.Color = color
	part.Material = Enum.Material.SmoothPlastic
	part.TopSurface = Enum.SurfaceType.Smooth
	part.BottomSurface = Enum.SurfaceType.Smooth
	part.Parent = parent
	return part
end

local function buildStage(spec)
	local stages = getStagesFolder()
	local name = "Stage" .. spec.number
	if stages:FindFirstChild(name) then
		error(name .. " already exists. Delete it in Studio first if a rebuild is intended.")
	end

	local model = Instance.new("Model")
	model.Name = name
	model:SetAttribute("Number", spec.number)
	model.Parent = stages

	local order = 0
	local function walkable(part)
		part:SetAttribute("Order", order)
		order += 1
	end

	for _, p in spec.parts do
		local position = spec.origin + p.offset
		if p.kind == "pad" then
			local className = if spec.number == 1 and p.stage == nil then "SpawnLocation" else "Part"
			local pad = newPart(className, "Checkpoint", p.size, position, p.color or PAD_COLOR, model)
			pad:SetAttribute("Stage", p.stage or spec.number)
			CollectionService:AddTag(pad, "Checkpoint")
			if pad:IsA("SpawnLocation") then
				pad.Neutral = true
				pad.Duration = 0
				-- Turn the pad so players spawn facing down the course (+Z).
				pad.CFrame = CFrame.new(position) * CFrame.Angles(0, math.pi, 0)
			end
			walkable(pad)
		elseif p.kind == "platform" then
			walkable(newPart("Part", "Platform", p.size, position, spec.color, model))
		elseif p.kind == "kill" then
			local kill = newPart("Part", "Kill", p.size, position, KILL_COLOR, model)
			kill.Material = Enum.Material.Neon
			CollectionService:AddTag(kill, "KillPart")
		elseif p.kind == "truss" then
			walkable(newPart("TrussPart", "Truss", p.size, position, spec.color, model))
		elseif p.kind == "conveyor" then
			local conveyor = newPart("Part", "Conveyor", p.size, position, spec.color, model)
			conveyor.Material = Enum.Material.DiamondPlate
			conveyor.AssemblyLinearVelocity = p.velocity
			conveyor:SetAttribute("ConveyorVelocity", p.velocity)
			CollectionService:AddTag(conveyor, "Conveyor")
			walkable(conveyor)
		elseif p.kind == "spinner" then
			local pivot = newPart("Part", "SpinnerPivot", Vector3.new(1, 1, 1), position, spec.color, model)
			pivot.Transparency = 1
			pivot.CanCollide = false
			pivot.CanTouch = false
			local bar = newPart("Part", "SpinnerBar", p.size, position, KILL_COLOR, model)
			bar.Material = Enum.Material.Neon
			bar.Anchored = false
			bar.CanCollide = false
			bar:SetAttribute("SpinSpeed", p.speed)
			CollectionService:AddTag(bar, "KillPart")
			CollectionService:AddTag(bar, "Spinner")
			-- A hinge turns about its attachments' X axis; rotate them so X points up.
			local pivotAttachment = Instance.new("Attachment")
			pivotAttachment.CFrame = CFrame.Angles(0, 0, math.pi / 2)
			pivotAttachment.Parent = pivot
			local barAttachment = Instance.new("Attachment")
			barAttachment.CFrame = CFrame.Angles(0, 0, math.pi / 2)
			barAttachment.Parent = bar
			local hinge = Instance.new("HingeConstraint")
			hinge.Attachment0 = pivotAttachment
			hinge.Attachment1 = barAttachment
			hinge.ActuatorType = Enum.ActuatorType.Motor
			hinge.AngularVelocity = p.speed
			hinge.MotorMaxTorque = math.huge
			hinge.Parent = pivot
		else
			error("unknown part kind: " .. tostring(p.kind))
		end
	end

	return string.format("%s built: %d instances", name, #model:GetDescendants())
end
```

- [ ] **Step 2: Write the gap checker**

Create `tools/check_gaps.luau`:

```lua
-- Run with execute_luau (Edit datamodel). Returns "OK ..." or a list of jumps that exceed the limits.
local StarterPlayer = game:GetService("StarterPlayer")
local Workspace = game:GetService("Workspace")

local jumpHeight = if StarterPlayer.CharacterUseJumpPower
	then StarterPlayer.CharacterJumpPower ^ 2 / (2 * Workspace.Gravity)
	else StarterPlayer.CharacterJumpHeight
local reach = StarterPlayer.CharacterWalkSpeed * 2 * math.sqrt(2 * jumpHeight / Workspace.Gravity)
local MAX_GAP = 0.75 * reach
local MAX_RISE = 0.6 * jumpHeight
local MAX_TRUSS_GAP = 1.5

local function bounds(part)
	local cf = part.CFrame
	local half = part.Size / 2
	local r, u, l = cf.RightVector, cf.UpVector, cf.LookVector
	local extent = Vector3.new(
		math.abs(r.X) * half.X + math.abs(u.X) * half.Y + math.abs(l.X) * half.Z,
		math.abs(r.Y) * half.X + math.abs(u.Y) * half.Y + math.abs(l.Y) * half.Z,
		math.abs(r.Z) * half.X + math.abs(u.Z) * half.Y + math.abs(l.Z) * half.Z
	)
	return cf.Position - extent, cf.Position + extent
end

local function numberOf(instance, attribute)
	local value = instance:GetAttribute(attribute)
	return if type(value) == "number" then value else 0
end

local stages = Workspace:FindFirstChild("Stages")
if not stages then
	return "Workspace.Stages does not exist"
end

local models = stages:GetChildren()
table.sort(models, function(a, b)
	return numberOf(a, "Number") < numberOf(b, "Number")
end)

local steps = {}
for _, model in models do
	local parts = {}
	for _, descendant in model:GetDescendants() do
		if descendant:IsA("BasePart") and type(descendant:GetAttribute("Order")) == "number" then
			table.insert(parts, descendant)
		end
	end
	table.sort(parts, function(a, b)
		return numberOf(a, "Order") < numberOf(b, "Order")
	end)
	for _, part in parts do
		table.insert(steps, part)
	end
end

local problems = {}
for i = 1, #steps - 1 do
	local a, b = steps[i], steps[i + 1]
	local aMin, aMax = bounds(a)
	local bMin, bMax = bounds(b)
	local dx = math.max(0, aMin.X - bMax.X, bMin.X - aMax.X)
	local dz = math.max(0, aMin.Z - bMax.Z, bMin.Z - aMax.Z)
	local gap = math.sqrt(dx * dx + dz * dz)
	local rise = bMax.Y - aMax.Y
	local label = string.format("%s[%d] -> %s[%d]", a.Parent.Name, numberOf(a, "Order"), b.Parent.Name, numberOf(b, "Order"))
	if a:IsA("TrussPart") or b:IsA("TrussPart") then
		if gap > MAX_TRUSS_GAP then
			table.insert(problems, string.format("%s: truss gap %.1f (max %.1f)", label, gap, MAX_TRUSS_GAP))
		end
	else
		if gap > MAX_GAP then
			table.insert(problems, string.format("%s: gap %.1f (max %.1f)", label, gap, MAX_GAP))
		end
		if rise > MAX_RISE then
			table.insert(problems, string.format("%s: rise %.1f (max %.1f)", label, rise, MAX_RISE))
		end
	end
end

if #problems == 0 then
	return string.format("OK: %d jumps checked, max gap %.1f, max rise %.1f", #steps - 1, MAX_GAP, MAX_RISE)
end
return table.concat(problems, "\n")
```

```lua
--!strict
local DataStoreService = game:GetService("DataStoreService")
local Players = game:GetService("Players")

local Rules = require(script.Parent.Rules)

local STORE_NAME = "PlayerData"
local SAVE_INTERVAL = 180
local MAX_ATTEMPTS = 5
local FIRST_RETRY_DELAY = 1

type Session = {
	stage: number,
	savedStage: number?,
}
type StageCallback = (player: Player, stage: number) -> ()

local PlayerData = {}

local sessions: { [Player]: Session } = {}
local stageChangedCallbacks: { StageCallback } = {}
local stageRestoredCallbacks: { StageCallback } = {}
local store: DataStore? = nil

local function keyFor(player: Player): string
	return "User_" .. player.UserId
end

local function fire(callbacks: { StageCallback }, player: Player, stage: number)
	for _, callback in callbacks do
		task.spawn(callback, player, stage)
	end
end

-- Runs fn up to MAX_ATTEMPTS times, waiting longer after each failure.
local function withRetries(description: string, fn: () -> any): (boolean, any)
	local delay = FIRST_RETRY_DELAY
	for attempt = 1, MAX_ATTEMPTS do
		local ok, result = pcall(fn)
		if ok then
			return true, result
		end
		warn(string.format("[PlayerData] %s failed (attempt %d of %d): %s", description, attempt, MAX_ATTEMPTS, tostring(result)))
		if attempt < MAX_ATTEMPTS then
			task.wait(delay * (1 + 0.5 * math.random()))
			delay *= 2
		end
	end
	return false, nil
end

local function load(player: Player)
	local dataStore = store
	if not dataStore then
		return
	end
	local ok, value = withRetries("load for " .. keyFor(player), function()
		return dataStore:GetAsync(keyFor(player))
	end)
	local session = sessions[player]
	if not ok or not session then
		return
	end
	local storedStage = if type(value) == "table" then Rules.sanitizeStage(value.stage) else Rules.FIRST_STAGE
	session.savedStage = storedStage
	if storedStage > session.stage then
		session.stage = storedStage
		fire(stageChangedCallbacks, player, storedStage)
		fire(stageRestoredCallbacks, player, storedStage)
	end
end

local function save(player: Player)
	local dataStore = store
	local session = sessions[player]
	if not dataStore or not session then
		return
	end
	local stage = session.stage
	if session.savedStage ~= nil and session.savedStage >= stage then
		return
	end
	local ok = withRetries("save for " .. keyFor(player), function()
		dataStore:UpdateAsync(keyFor(player), function(old: any)
			local data = if type(old) == "table" then old else {}
			data.stage = Rules.mergeStage(data.stage, stage)
			return data
		end)
		return nil
	end)
	if ok then
		session.savedStage = stage
	end
end

local function onPlayerAdded(player: Player)
	if sessions[player] then
		return
	end
	local session: Session = { stage = Rules.FIRST_STAGE, savedStage = nil }
	sessions[player] = session
	task.spawn(load, player)
	task.spawn(function()
		task.wait(math.random() * SAVE_INTERVAL)
		while sessions[player] == session do
			save(player)
			task.wait(SAVE_INTERVAL)
		end
	end)
end

local function onPlayerRemoving(player: Player)
	save(player)
	sessions[player] = nil
end

local function onClose()
	local pending = 0
	for player in sessions do
		pending += 1
		task.spawn(function()
			save(player)
			pending -= 1
		end)
	end
	while pending > 0 do
		task.wait()
	end
end

function PlayerData.getStage(player: Player): number
	local session = sessions[player]
	return if session then session.stage else Rules.FIRST_STAGE
end

function PlayerData.setStage(player: Player, stage: number)
	local session = sessions[player]
	if not session or session.stage == stage then
		return
	end
	session.stage = stage
	fire(stageChangedCallbacks, player, stage)
end

function PlayerData.onStageChanged(callback: StageCallback)
	table.insert(stageChangedCallbacks, callback)
end

function PlayerData.onStageRestored(callback: StageCallback)
	table.insert(stageRestoredCallbacks, callback)
end

function PlayerData.start()
	local ok, result = pcall(function()
		return DataStoreService:GetDataStore(STORE_NAME)
	end)
	if ok then
		store = result
	else
		warn("[PlayerData] data store unavailable; progress will not be saved this session: " .. tostring(result))
	end

	Players.PlayerAdded:Connect(onPlayerAdded)
	for _, player in Players:GetPlayers() do
		onPlayerAdded(player)
	end
	Players.PlayerRemoving:Connect(onPlayerRemoving)
	game:BindToClose(onClose)
end

return PlayerData
```

```lua
--!strict
local CollectionService = game:GetService("CollectionService")
local Players = game:GetService("Players")

local Touch = {}

-- Returns the player whose living character the touching part belongs to.
function Touch.getLivingPlayer(hit: BasePart): (Player?, Humanoid?)
	local model = hit:FindFirstAncestorOfClass("Model")
	while model do
		local player = Players:GetPlayerFromCharacter(model)
		if player then
			local humanoid = model:FindFirstChildOfClass("Humanoid")
			if humanoid and humanoid.Health > 0 then
				return player, humanoid
			end
			return nil, nil
		end
		model = model:FindFirstAncestorOfClass("Model")
	end
	return nil, nil
end

-- Calls callback(part, hit) whenever a part carrying the tag is touched,
-- including parts tagged after this call.
function Touch.onTagTouched(tag: string, callback: (part: BasePart, hit: BasePart) -> ())
	local connections: { [Instance]: RBXScriptConnection } = {}

	local function add(instance: Instance)
		if instance:IsA("BasePart") and not connections[instance] then
			connections[instance] = instance.Touched:Connect(function(hit: BasePart)
				callback(instance, hit)
			end)
		end
	end

	local function remove(instance: Instance)
		local connection = connections[instance]
		if connection then
			connection:Disconnect()
			connections[instance] = nil
		end
	end

	CollectionService:GetInstanceAddedSignal(tag):Connect(add)
	CollectionService:GetInstanceRemovedSignal(tag):Connect(remove)
	for _, instance in CollectionService:GetTagged(tag) do
		add(instance)
	end
end

return Touch
```

```lua
--!strict
local CollectionService = game:GetService("CollectionService")
local Workspace = game:GetService("Workspace")

local PlayerData = require(script.Parent.PlayerData)
local Rules = require(script.Parent.Rules)
local Touch = require(script.Parent.Touch)

local TAG = "Checkpoint"
local STAGE_ATTRIBUTE = "Stage"

local Checkpoints = {}

local function getPadStage(pad: Instance): number?
	local stage = pad:GetAttribute(STAGE_ATTRIBUTE)
	if type(stage) == "number" then
		return stage
	end
	return nil
end

-- Returns the pad for the given stage, or for the highest stage below it when that pad does not exist.
function Checkpoints.getPad(stage: number): BasePart?
	local best: BasePart? = nil
	local bestStage = -math.huge
	for _, instance in CollectionService:GetTagged(TAG) do
		if instance:IsA("BasePart") and instance:IsDescendantOf(Workspace) then
			local padStage = getPadStage(instance)
			if padStage and padStage <= stage and padStage > bestStage then
				best = instance
				bestStage = padStage
			end
		end
	end
	return best
end

function Checkpoints.start()
	local seen: { [number]: boolean } = {}
	for _, instance in CollectionService:GetTagged(TAG) do
		local padStage = getPadStage(instance)
		if not padStage then
			warn("[Checkpoints] pad has no number attribute 'Stage': " .. instance:GetFullName())
		elseif seen[padStage] then
			warn(string.format("[Checkpoints] more than one pad for stage %d: %s", padStage, instance:GetFullName()))
		else
			seen[padStage] = true
		end
	end

	Touch.onTagTouched(TAG, function(pad: BasePart, hit: BasePart)
		local padStage = getPadStage(pad)
		if not padStage then
			return
		end
		local player = Touch.getLivingPlayer(hit)
		if not player then
			return
		end
		local current = PlayerData.getStage(player)
		local nextStage = Rules.nextStage(current, padStage)
		if nextStage ~= current then
			PlayerData.setStage(player, nextStage)
		end
	end)
end

return Checkpoints
```

```lua
--!strict
local Players = game:GetService("Players")
local RunService = game:GetService("RunService")
local Workspace = game:GetService("Workspace")

local Checkpoints = require(script.Parent.Checkpoints)
local PlayerData = require(script.Parent.PlayerData)
local Rules = require(script.Parent.Rules)

-- Height of the character's pivot above the pad's top surface.
local PAD_CLEARANCE = 4

local Spawning = {}

-- Stage 1 needs nothing: the engine spawns characters on the stage 1 pad, which is a SpawnLocation.
local function placeOnPad(player: Player)
	local stage = PlayerData.getStage(player)
	if stage == Rules.FIRST_STAGE then
		return
	end
	local character = player.Character
	local pad = Checkpoints.getPad(stage)
	if not character or not pad then
		return
	end
	local position = pad.Position + Vector3.new(0, pad.Size.Y / 2 + PAD_CLEARANCE, 0)
	-- The course runs along +Z, so face that way.
	character:PivotTo(CFrame.lookAt(position, position + Vector3.zAxis))
end

local function onCharacterAdded(player: Player, character: Model)
	character:WaitForChild("HumanoidRootPart")
	if not character:IsDescendantOf(Workspace) then
		character.AncestryChanged:Wait()
	end
	-- Let the engine finish its own spawn placement before moving the character.
	RunService.Heartbeat:Wait()
	if player.Character == character then
		placeOnPad(player)
	end
end

function Spawning.start()
	local function onPlayerAdded(player: Player)
		player.CharacterAdded:Connect(function(character: Model)
			onCharacterAdded(player, character)
		end)
		local character = player.Character
		if character then
			task.spawn(onCharacterAdded, player, character)
		end
	end

	Players.PlayerAdded:Connect(onPlayerAdded)
	for _, player in Players:GetPlayers() do
		onPlayerAdded(player)
	end

	PlayerData.onStageRestored(function(player: Player)
		placeOnPad(player)
	end)
end

return Spawning
```
